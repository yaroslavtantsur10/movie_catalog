# Лабораторна робота №1

**Тема:** Функції та обробка колекцій мовою Dart  
**Варіант 2:** Каталог фільмів

## Опис програми

У цій лабораторній роботі я зробив консольну програму для роботи з каталогом фільмів.

У програмі є 15 записів про фільми. Частина записів містить помилки, тому спочатку програма перевіряє дані, а потім працює тільки з правильними записами.

Програма може:

- знаходити неправильні записи;
- рахувати середній рейтинг фільмів;
- рахувати загальну тривалість;
- вибирати фільми за рейтингом;
- групувати фільми за жанрами;
- сортувати фільми за рейтингом і роком;
- працювати з датами та регулярними виразами;
- формувати текстовий звіт.

## Структура проєкту

Проєкт я розділив на декілька файлів:

- `bin/movie_catalog.dart` — тут запускається програма та виводяться результати в консоль.
- `lib/movie_catalog.dart` — тут знаходяться дані про фільми та функції для їх обробки.
- `test/movie_catalog_test.dart` — тести для перевірки роботи функцій.
- `pubspec.yaml` — залежності та налаштування проєкту.
- `analysis_options.yaml` — налаштування перевірки коду.

Я розділив програму таким чином, щоб не писати все в одному файлі. Так зручніше знаходити потрібні функції та перевіряти їх окремо.

## Типи даних

Спочатку інформація про фільми зберігається у `List<String>`. Кожен рядок містить назву фільму, режисера, рік, тривалість, жанр і рейтинг.

Для одного фільму я використав `record` з назвою типу `Movie`. Це зручно, тому що в кожного фільму однакові поля. Можна було створити клас `Movie`, але для цієї роботи мені вистачило `record`.

Після перевірки фільми зберігаються у `List<Movie>`. Список підходить, тому що потрібно перебирати, фільтрувати та сортувати фільми.

Для групування за жанрами я використав `Map<String, List<Movie>>`. У ньому назва жанру є ключем, а значенням є список фільмів цього жанру.

## Як працює програма

Функція `parseMovie()` розділяє рядок на окремі частини та перетворює їх у потрібні типи. Для чисел використовується `tryParse()`, щоб програма не завершувалася з помилкою через неправильні дані.

Функція `validateMovie()` перевіряє рік випуску, тривалість і рейтинг.

Для роботи зі списками я використав `where`, `map` і `fold`. Наприклад, `where` потрібен для фільтрації, а `fold` — для підрахунку суми рейтингів і тривалості.

Також у програмі є сортування за двома полями, робота з `DateTime` і `Duration`, заміна років у тексті через `RegExp` та лічильник на основі замикання.

Для створення текстового звіту використовується `StringBuffer`. Це зручніше, ніж постійно додавати рядки через `+`.

## Залежності

У проєкті використовуються два пакети з pub.dev:

- `test` — потрібен для автоматичної перевірки функцій. За допомогою `test()` та `expect()` можна перевірити, чи повертає функція правильний результат.
- `lints` — містить рекомендовані правила для перевірки коду Dart. Ці правила використовуються під час запуску `dart analyze`.

Обидва пакети потрібні для розробки та перевірки програми. Для самої обробки фільмів додаткові пакети не використовуються.

Замість `test` можна було перевіряти функції вручну або через `assert()`, але з пакетом зручніше запускати всі перевірки одразу.

Замість `lints` можна було самостійно налаштувати правила аналізатора. Я залишив готовий набір правил, тому що його достатньо для цієї лабораторної.

## Запуск програми

Спочатку потрібно встановити залежності:

```bash
dart pub get
```

Після цього запустити програму:

```bash
dart run
```

## Перевірка

Для перевірки коду використовується команда:

```bash
dart analyze
```

Для запуску тестів:

```bash
dart test
```

Також можна перевірити форматування:

```bash
dart format .
```

Усього написано 10 тестів. Вони перевіряють зчитування даних, пошук помилок, фільтрацію, групування, сортування, регулярні вирази та формування звіту.

## Результат роботи

Програма обробляє 15 записів про фільми. Із них 12 записів правильні, а 3 містять помилки.

Для правильних записів програма обчислює статистику, виводить фільми за жанрами та показує результати сортування.

## Висновок

Під час виконання лабораторної роботи я попрактикувався у використанні функцій та колекцій Dart. Також розібрався з `record`, `Map`, `DateTime`, регулярними виразами та написанням тестів.

Найбільше уваги приділив перевірці даних, тому що не всі початкові записи правильні.
